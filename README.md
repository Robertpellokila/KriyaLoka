## 🌿 About the Project

**KriyaLoka** is a digital marketplace designed to empower local Micro, Small, and Medium Enterprises (UMKM) in Bali.

The platform aims to help local businesses showcase their products, reach a wider audience, and embrace digital technology.

By bringing local creativity and modern technology together, KriyaLoka creates opportunities for Balinese businesses to grow in the digital economy.

### 🎯 Our Mission

- **Empower Local Businesses** — Help Balinese UMKM establish their digital presence.
- **Promote Local Products** — Make unique local products easier to discover.
- **Connect Communities** — Build connections between local sellers and customers.
- **Support Digital Transformation** — Encourage small businesses to adopt digital solutions.

## 🚀 Getting Started

Follow these steps to run KriyaLoka locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) (recommended: LTS)
- npm
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/Robertpellokila/KriyaLoka.git
```

### 2. Navigate to the Project

```bash
cd KriyaLoka
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local URL provided by Vite, usually:

```bash
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```
